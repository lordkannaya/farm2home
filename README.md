# 🌱 Farm2Home – Direct Farmer Selling Platform

## 📌 Project Description
Farm2Home is a full-stack web application that connects farmers directly with customers. It allows farmers to sell fresh products online and customers to buy them easily without middlemen.

## 🚀 Features
- 👨‍🌾 Farmer Login & Dashboard
- 🧑‍💻 Customer Login
- 🛒 Product Listing & Buying
- 📦 Order Tracking
- ⭐ Rating & Review System
- 🛠 Admin Panel

## 🛠 Tech Stack
- Backend: Python Flask
- Frontend: HTML, CSS, JavaScript
- Database: SQLite

## ▶️ How to Run

pip install flask
python app.py
